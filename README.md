# AfterClass

AfterClass is a simple website intended to bring commonly used classroom websites and educational resources together in one place.

All pages share `style.css`, which provides the dark theme, navigation banner, and page layout.

## Color theme

- Background: charcoal (`#121212`)
- Header and footer: dark gray (`#1e1e1e`)
- Accent: red (`#e53935`), with a lighter red hover state (`#ff8a80`)

## Keyboard shortcut

Press `0` to open Google, including while typing or interacting with the page.

## Run locally

No build tools or dependencies are required. Open `index.html` in a web browser, or serve the project directory with any static file server.
